flake et black
	flake8
		vérifier la qualité du code sans modifier

	black
		formater le code

	de base :
	● Black utilise 88 caractères par ligne
	● Flake8 utilise 79 caractères par ligne

	config dans .flake
		extend-ignore = E203, W503
			ça évite des conflits potentiels avec Black

		on ignore les erreurs dans le venv et le pycache
